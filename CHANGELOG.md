# Release notes

## 0.1.1 — 2026-11-03

- Removed the Save button from the popup and settings page. All edits now save automatically.
- Incomplete edits are retained when the popup closes. The last working rules remain active until the edits can be applied.
- Valid edits to the active profile apply automatically. A Grant site access button appears when additional website access is needed.
- Rapid edits keep their latest values while earlier saves finish.

Existing profiles and settings are retained when updating the installed extension.
