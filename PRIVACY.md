# Privacy Policy for CrunchrHeader

**Effective date:** September 29, 2026  
**Developer:** Wouter Sondagh  
**Privacy contact:** crunchrheader@sondagh.net

CrunchrHeader is a Chrome extension for creating and applying user-configured HTTP request and response header profiles to selected websites.

## Information CrunchrHeader stores

CrunchrHeader stores the settings you create in Chrome's local extension storage. These settings can include profile names, header names and values, URL filters, excluded domains, and whether the extension or a profile is enabled. Header values may contain authentication information if you choose to enter it.

The extension uses these settings only to apply the header changes you configure, to display and manage your profiles, and to import or export your settings at your request.

## How information is used and transmitted

Profile settings are stored locally in your Chrome profile. CrunchrHeader does not send profile settings to the developer or to a developer-controlled server. The extension does not include analytics, advertising, or remote reporting code.

When you enable a profile, Chrome applies its rules to requests matching the URL filters you configured. Request-header values in those rules are sent by your browser to the matching websites as part of those requests. Response-header rules modify matching responses in your browser. The websites that receive your requests handle them under their own privacy policies.

CrunchrHeader requests website access through Chrome only when needed to apply a profile. You can grant or deny that access in Chrome. If you export profiles, the extension creates a JSON file on your device containing your settings; the file may include sensitive header values. You choose where to save and whether to share that file.

## Sharing

The developer does not sell, share, or receive your profile settings. The extension does not transmit them to third parties. As described above, websites you configure may receive request-header values when Chrome sends matching requests. Chrome itself processes extension storage, permissions, and network requests as part of providing the browser; Chrome's own data practices are described in Google's privacy documentation.

## Your choices and control

You can view, change, or delete profiles in the extension. You can also turn the extension off, revoke its website access in Chrome, or remove the extension. Exported JSON files are separate copies; delete them wherever you saved them if you no longer want to keep them.

## Security

Profile settings remain in Chrome's local extension storage unless you export them. Protect access to your device and Chrome profile. Treat exported JSON files as sensitive if they contain credentials or other secrets.

## Changes and contact

If CrunchrHeader's data practices change, this policy will be updated before the changed practices take effect. For privacy questions, contact crunchrheader@sondagh.net.

## Chrome Web Store Limited Use

The use of information handled by CrunchrHeader complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. CrunchrHeader uses profile information only to provide its disclosed purpose of applying user-configured HTTP header rules.
